# CRCL 经营台

Circle Internet Group（NYSE: CRCL）的行情、储备收入模型和相对估值，放在同一张工作台上。

假设存在浏览器本地。关掉页面再打开，上次拨过的滑杆还在。点「恢复默认假设」就回到内置口径。

## 页面上有什么

- **行情**：最新价、涨跌、市值、成交量、日内区间、52 周区间
- **储备收入模型**：USDC 流通量、国债利率，加上 Arc、CCTP、CPN 的手续费，折成年化 EBITDA，再乘倍数得到股价区间
- **相对估值**：目标市销率和远期市盈率各算一个价，取中位
- **实时驱动**：链上供应量、稳定币份额、13 周国债，以及 Arc / CCTP / CPN 的近期数据

链上供应量和国债大约每分钟拉一次。季报里的历史数字不会在这里自动变。

## 模型在算什么

经营区间按年化调整后 EBITDA 的倍数带给出。分销费先从收入里扣掉，再扣经营费用，才拿去乘倍数。

可以改的假设包括：

- 储备收益率：国债减现金拖累、季报口径，或自定义
- 净储备利润率、EBITDA 转化率、其他收入
- 自己的 EBITDA 倍数
- Arc 的分成、CPN 的假设净抽成
- 目标市销率、远期 EPS、目标市盈率、股数

这些是可调的工作假设，不是公司指引，也不是预测。

## 本地运行

```bash
npm install
npm run dev
```

开发服务默认在 `8080` 端口。生产构建：

```bash
npm run build
```
